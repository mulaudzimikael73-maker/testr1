# YourUltimateFan

Static GitHub Pages website for LizzyOS.

## Publish with GitHub Desktop

1. Create or clone an empty public repository.
2. Copy every item from this folder into the cloned repository folder.
3. In GitHub Desktop, commit the changes and click **Push origin**.
4. In GitHub: **Settings → Pages → Deploy from a branch → main → /(root)**.
5. The site URL will be `https://<username>.github.io/<repository-name>/`.

## Updating Read Me media

1. Open `upload.html` locally in a browser.
2. Choose the current `data/readme.json`.
3. Choose new photos/videos and upload them.
4. Download the updated `readme.json`.
5. Replace `data/readme.json`, then commit and push through GitHub Desktop.

Media is hosted through Cloudinary; the repository does not need local gallery/video copies.
